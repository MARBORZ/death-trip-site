# Death Trip Site

En moderne, mørk-tema nettside bygget med React, TypeScript og Motion (Framer Motion). Har jevn scrolling med Lenis og elegante animasjoner.

## 🎨 Om

Death Trip er en visuelt slående nettside med mørk estetikk, jevn scroll-oppførsel og flytende animasjoner. Bygget med moderne webteknologier for optimal ytelse.

## ✨ Funksjoner

- **Jevn Scrolling** — Lenis-integrasjon for silkemyk scroll
- **Motion Animasjoner** — Flytende animasjoner med Motion-bibliotek
- **Mørkt Tema** — Elegant mørk estetikk
- **TypeScript** — Full typesikkerhet
- **Responsivt Design** — Fungerer på alle enheter
- **Vite** — Rask utvikling og optimaliserte bygg

## 🛠️ Teknologi

- **React** — UI-bibliotek
- **TypeScript** — Typesikker utvikling
- **Vite** — Byggeverktøy
- **Motion** — Animasjonsbibliotek
- **Lenis** — Smooth scroll
- **ESLint** — Kodekvalitet

## 🚀 Kom i Gang

```bash
npm install
npm run dev
```

Åpne `http://localhost:5173`
